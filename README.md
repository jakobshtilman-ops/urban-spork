# טקטיק (Tactic) - מנהל משימות וביצועים רב-שלבי עצמאי ואופליין

אפליקציה מתקדמת לניהול משימות אישיות ועסקיות לפי שעות, ימים, שבועות, חודשים, שנים ומותאם אישית, כולל התחדשות אוטומטית במחזור הבא, לוח שנה עברי מלא (באותיות וללא מספרים), מעקב רצפי הצלחה (Streaks), ארכיון והיסטוריית משימות נפרדת, ותמיכה מלאה ב-100% פעילות אופליין מקומית.

---

## 1. איך GitHub יודע ליצור מזה אפליקציה וקובץ EXE?

הפרויקט כולל הגדרות אוטומטיות מלאות באמצעות **GitHub Actions**, עם שתי אפשרויות אריזה לבחירתך:

1. **אריזת Electron (מומלצת ומוכנה מיידית ל-Windows EXE):**
   - קובץ ה-Workflow: `.github/workflows/build-exe.yml`
   - מפיק: קובץ התקנה `Tactic-Setup.exe` מלא ועצמאי.
2. **אריזת Tauri (קובץ קל-משקל בטכנולוגיית Rust):**
   - קובץ ה-Workflow: `.github/workflows/build.yml`
   - קבצי הקונפיגורציה: תיקיית `src-tauri` (`tauri.conf.json`, `Cargo.toml`, `src/main.rs`).
   - מפיק: קובץ `msi` / `exe` קל-משקל במיוחד.

### כיצד התהליך עובד שלב-אחר-שלב:
1. **העלאת הקוד ל-GitHub (`git push`)**:
   ברגע שאתה דוחף את הקוד למאגר (Repository) ב-GitHub, ה-Workflows מופעלים אוטומטית.
2. **הקצאת שרת Windows של GitHub**:
   GitHub Actions מקצה מכונה וירטואלית (`windows-latest`) ייעודית.
3. **התקנת תלויות ובנייה**:
   - הרצת `npm install` להתקנת כל המודולים.
   - הרצת `npm run build` לקמפול ממשק ה-React וה-Tailwind לקבצים מקומיים עצמאיים (`dist`).
4. **אריזה לקובץ התקנה**:
   - ב-Electron: הרצת `electron-builder` לפי הגדרות `package.json` ו-`electron/main.cjs`.
   - ב-Tauri: הרצת `tauri-action` וקמפול בינארי באמצעות מנוע Rust.
5. **הורדת הקובץ המוגמר מ-GitHub**:
   - בתוך המאגר שלך ב-GitHub, לחץ על לשונית **Actions**.
   - לחץ על הריצה של **Build Standalone Windows EXE** או **Build Lightweight Executable (Tauri)**.
   - גלול מטה לחלק **Artifacts** — שם תמצא את הקובץ מוכן להורדה ישירה בלחיצה אחת!

## 2. משימות שהושלמו ואינן מתחדשות (היסטוריית משימות / ארכיון)

- משימות חד-פעמיות שהושלמו (כלומר `completed = true` ו-`renewOnNextPeriod = false`) **אינן מופיעות בלוח המשימות הראשי**, כדי לשמור על לוח עבודה נקי וממוקד.
- הן מועברות ישירות ללשונית הייעודית **"היסטוריית משימות"** בסרגל הניווט העליון.
- בלשונית זו ניתן:
  - לצפות בתאריך השלמה עברי מלא
  - לראות האם המשימה הושלמה בזמן או באיחור (עם כמות ימי האיחור)
  - לבדוק את משך הביצוע
  - להחזיר משימה למצב פעיל בלחיצה אחת (↩️)
  - להפוך משימה חד-פעמית למחזורית מתחדשת (🔄)
  - לשכפל או למחוק לצמיתות
  - לייצא גיבוי JSON של כל ההיסטוריה

## 3. דרכים נוספות להפעלת האפליקציה במחשב ללא אינטרנט כבר עכשיו

1. **אפליקציית שולחן עבודה מותקנת (PWA)**:
   - לחץ על כפתור "התקן למחשב" (🖥️) בסרגל העליון בדפדפן (Chrome / Edge).
   - האפליקציה תותקן כתוכנת מחשב מלאה עם אייקון בשולחן העבודה ותפעל 100% אופליין.
2. **קובץ הרצה מקומי ל-Windows (`windows-offline-launcher.bat`)**:
   - לחיצה כפולה על הקובץ `windows-offline-launcher.bat` פותחת את המערכת בחלון עצמאי במחשב שלך.
3. **קובץ HTML בודד ועצמאי**:
   - לחץ על כפתור "HTML עצמאי" להורדת קובץ יחיד שמכיל את כל המערכת. ניתן להעתיק אותו לכל דיסק-און-קי ולהריץ בכל מחשב ללא התקנה.

## 4. שמירת נתונים פיזית על המחשב (ולא רק בדפדפן)

המערכת מצוידת במנגנון אחסון ישיר בדיסק המקומי של המחשב:

1. **באפליקציית שולחן עבודה (Tauri):**
   - הוטמעו פקודות Rust מקוריות (`save_tasks_to_disk` ו-`load_tasks_from_disk`).
   - כל שינוי, הוספה או סימון משימה נכתב אוטומטית לקובץ פיזי בדיסק הקשיח:
     `%APPDATA%\Tactic\tactic-tasks.json`.
2. **בדפדפן / PWA (File System Access API):**
   - לחיצה על כפתור **"שמירה במחשב"** (💾) בסרגל העליון מאפשרת לחבר קובץ קבוע במחשב (`tactic-tasks.json`).
   - לאחר הבחירה, הדפדפן כותב ומעדכן את הקובץ ישירות בדיסק הקשיח בכל שינוי נתונים.
3. **שמירה ידנית וטעינה מהירה:**
   - כפתור **"שמור קובץ במחשב כעת"** לשמירת עותק JSON מיידי לתיקיית ההורדות או המסמכים.
   - כפתור **"טען קובץ מהמחשב"** לשחזור וטעינת משימות מכל קובץ מקומי.
